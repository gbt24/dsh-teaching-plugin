**接口错误/取消/恢复语义**

- 所有公开方法返回 `Result`；预期失败不 throw：`invalid-input`（不支持格式/路径为空）、
  `not-found`（文件或资料不存在）、`limit-exceeded`（超单文件上限）、`failed`（解析失败，
  `details.cause=corrupt-pdf|binary-content|invalid-docx…`）、`cancelled`、`uncertain`
  （课程草案两次都无法解析）、`capability-missing`（无模型）、`stale-revision`（anchor 指向旧修订）、
  `storage`（记录损坏）。
- `importFiles` 的取消：`onProgress` 可调用 `signal` 的 abort；已完成的文件保留可用，
  返回 `warnings` 说明“已完成 X/Y、剩余 N 未处理”；循环不会无限重试，单文件失败不影响其它文件。
- 已就绪资料/课程不受后台导入影响（测试 `import-many.test.ts` 覆盖）。

**`importFiles` 进度约定**：`onProgress(done, total, current)`。
开始前调用一次 `(0, total, 第一个路径)`，每完成一个文件调用一次 `(已完成数, total, 该文件路径)`；
当前文件失败也计入 `done`，失败项进入 `failures`。

**`search` 返回**：`CorpusSearchResult { hits: { anchor, documentTitle, score, matchedTerms }[], empty }`。
`anchor` 是可直接用于引用/回解的 `SourceAnchor`（含真实 unitId/修订/locator/excerpt/confidence）；
`empty=true` 时 `hits=[]`（不编造）。过滤：`courseId`、`alsoCourseIds`、`documentIds`、`kinds`、`limit`
（默认 10，最大 100）。

**`proposeCourseStructure` 输入**：`CourseDraftInput { courseId, courseTitle, goal, background?,
language, documentIds?, instruction? }`，第二个参数 `AbortSignal` 可选；需要注入 `model`，
否则返回 `capability-missing`。产出 `CourseRevision`（state=`draft`，provenance=`ai-draft`，
version 递增，basedOn 为使用的资料当前修订），并更新 `Course.draftRevisionId`；
**不会修改 activeRevisionId**（确认由 Host/学生完成）。

   与 `courseDraft.generate`（`proposeCourseStructure` + `buildCourseDraftCoverage`）路由。

图表/公式：
- Markdown/HTML 公式保留 TeX 原文；HTML MathML 保留纯文本并标记 `formula-uncertain`。
- Word OMML 公式按纯文本保留（不做 TeX 反解），标记 `formula-uncertain`（info）。
- PDF 内嵌位图从 operator list 提取并编码为 PNG 资产（页面 bbox）；扫描页整页图也作为 figure 资产。
- Word/PPT/Notebook 的图片写入修订资产目录，`assetPath` 相对资产目录；测试验证文件存在。
- 代码保留语言与行号（`ParsedSource.detail` + unit notes；见「契约扩展」）。

### 不能/不确定内容如何进入教学层

- `SourceIssue.reviewRequired=true` 会写入修订，经 `readUnits/getRevision/listIssues` 传给教学层：
  - OCR 平均置信度 < 70 → `ocr-low-confidence`（examples：本样例扫描公式 `< 70` 时出现）；
  - OCR 识别出疑似公式 → `formula-uncertain`（warning + reviewRequired，防止错误公式被当资料结论）；
  - 扫描页无文字且 OCR 不可用/失败 → `scan-no-text`（warning + reviewRequired）；
  - 图片缺失 → `figure-unreadable`（warning + reviewRequired）；正文继续可用；
  - 超限截断 → `truncated`（warning + reviewRequired）。
- 单元 `confidence`：文字型 PDF/Office/代码为 high；OCR 为 medium/low；未知为 unknown。
- 修订 `status`：ready / partial / needs-review / failed；文档 `status` 与之一致。
- 资料更新解析失败时写入 `failed` 修订（history 保留旧修订），`SourceChange.effects.needsConfirmation=true`，
  教学层可据此保留旧依据并提示学生；旧修订仍可按 anchor 回解（测试覆盖）。

## 课程草案实测（ScriptedModelClient）

- 有效 JSON：产出 `CourseRevision`（draft/version=1），概念 anchor 全部对应真实
  `documentId/revisionId/unitId`，`sequence` 覆盖全部概念，`basedOn` 记录所读修订，
  `Course.draftRevisionId` 更新且 activeRevisionId 不变；`buildCourseDraftCoverage`
  返回每份资料的 usedUnits/issues 与 warnings。
- JSON 解析失败：只做**一次**修复调用（第二次请求带错误原因与「只输出 JSON」要求），成功则保存草案。
- 两次失败/缺字段：返回 `uncertain`，**不保存**任何修订（测试断言 revisions 为空）。
- 伪造 anchor（不存在的 unitId）：丢弃该 anchor（概念 sourceAnchors 为空），
  `changeSummary` 记录「N 个模型引用无法对应到真实资料单元，已丢弃」，coverage warnings 提示。
- 模型取消 → `cancelled`；未注入模型 → `capability-missing`；课程不存在 → `not-found`。
- 重新生成：新版本 draft；旧 draft 标记 `superseded`；已确认版本（active）不受影响。

## 变化检测与更新实测

- 未变化：mtime/size 相同或仅 mtime 变化但内容哈希相同 → `changed=false`（后者刷新记录的 mtime）。
- 内容变化：SHA-256 不同 → `changed=true`，`effects.affectedConceptIds` 由课程修订
  `sourceAnchors` 反查（测试：概念引用被修改的正文单元时被列出）；活动由 Host hook 注入。
- 缺文件：`changed=true`、`currentFingerprint='missing'`，文档标记 `missing`；恢复文件后可继续。
- 刷新成功：生成新修订、旧修订保留；单元级 diff 报告新增/删除/修改数量；标题结构变化或
  受影响比例 ≥30% 时 `needsConfirmation=true`。实测：新增 2 / 删除替换 8 个单元 → 3.2ms。
- 刷新失败（二进制垃圾覆盖 .md）：写入 `failed` 修订，文档 status=failed，summary 说明
  「更新失败…旧修订保留」，`listIssues` 可见 error 问题。
- Host 注入 hook：`conceptsForDocument`/`activitiesForDocument` 用于 detect；
  `conceptsForUnits`/`activitiesForUnits` 用于 refresh（测试验证回调收到受影响 unitId）。

## 局限与未完成项

1. **PDF 段落粒度**：文字 PDF 按行合并为段落时较保守（本样例单页合并为 1 个 paragraph 单元）；
   跨行/双栏/页眉页脚未做版式分析，定位精度到页 + 行框 bbox，不是字符级。
2. **Office 段落定位**：契约 `SourceLocator` 无“段落序号”字段，Word 用 `chars` 区间 +
   notes 中“Word 第 N 段”；见下方契约扩展建议。
3. **Office 公式**：OMML 只保留纯文本、标记不确定；不做 TeX 反解。PPT 图表对象不反解数据（显式 issue）。
4. **代码语言**：`SourceUnit` 无 language 字段，语言放在 `ParsedSource.detail` 与 unit notes；
   代码未做语法高亮/符号级定位。
5. **OCR**：单份资料 OCR 页数默认上限 120（超出 `truncated`）；公式识别仅启发式，扫描公式一律
   `reviewRequired`；依赖宿主 tesseract/pdftoppm，缺失时降级为可报告状态而非失败。
6. **检索质量**：BM25 + CJK 二元组，无同义词/跨语言映射（查询“derivative”不会自动命中纯中文段落，
   需中英词同时出现在文本中）；索引按文档加载，超大规模（数百份）首次检索需要逐文档加载索引；
   旧修订的索引文件不会主动清理（属可重建缓存，长时间使用会累积）。
7. **目录缓存**：`cache/corpus-catalog.json` 为单实例内存 + 落盘缓存，多实例并发写可能短暂
   覆盖彼此（正确性以 `sources/*.json` 对账为准，新实例会重建）；Host 应保持单实例写入。
8. **未覆盖格式**：xlsx、音频/视频、加密 PDF（显式失败）、复杂扫描版式（表格/公式）。
9. **规模数字**不是桌面进程内测量，也不是真实课程资料（真实资料留在用户本地，仓库只用可分发样例）。
