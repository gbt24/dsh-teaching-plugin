补充实测的宿主接口事实（已写入 `technical-decisions.md`）：

- exact Fetch route 必须注册在 `/api/` 前缀下（`/api/xxx`），否则激活期抛 `invalid exact Fetch route`；路由对非 owner peer 返回 403。
- `main`（keyed, root scope）+ `sidebar.panellist`（list, root scope）是「左侧栏入口 + 中央页面」的官方组合；panel id 同时作为 main 的 key 与 panellist 的 id，点击由 sidebar 调 `ctx.layout.selectPanel(id)`。
- Client bundle 是 `window.__ModuleLoader__.load({ id, factory: require => … })` 包装的 CJS；`react`/`react/jsx-runtime` 等 baseline 模块由宿主 require 注入。
- `dsh plugin --profile <name> add|remove` 是 bundled CLI 的官方包管理入口；desktop profile 由 Electron 应用独占管理。

## 阻断、局限与下一步

1. **桌面 profile 安装路径**：本会话文件沙箱为 workspace-write，bash 写入 `~/.dsh` 被拒（EPERM）；应用内 `plugin_manager` 工具（live profile，HMR 开启时 `applied`）需要 danger-full-access / 用户批准。下一步：T01 完成后用 `plugin_manager` 安装正式插件包，并请用户刷新/重启 Desktop 窗口确认左侧栏入口；这同时作为 AC01 的第一份真实桌面证据。
2. **Electron 窗口自动化**：Desktop 启动时未带 `--remote-debugging-port`，CDP 不可用；本会话内不重启用户应用。T08 前需与用户约定一次带调试端口的重启或由用户目视确认。
3. **离线断网**：V8 为 Chrome `offline` 网络仿真，非物理断网；T07 需真实断网复验。
4. **用量/费用**：spike 未采集 token usage；T01 的模型桥接必须记录 usage 与耗时，费用未知时如实显示未知。
5. **HMR/live 重载**：dev profile 未启用 HMR 根；插件安装后的 live 重载与重启语义留到 T01/T08 验证。

下一步入口：**T01**——冻结项目布局与公共契约，建立 LocalState/模型桥接，打通「单份文本资料 → 有来源讲解 → 活动 → 尝试 → 重启续学」最小纵向流程。
