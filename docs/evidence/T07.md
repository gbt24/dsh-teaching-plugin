## 公开 seam 与接线约定（Lead 已批准）

```ts
import { createPortabilityService } from '@deepseek-teaching/core/portability'
const portability = createPortabilityService({
  state, courses, sessions, learning, profiles, // 现有仓库实例
  pluginVersion, appVersion,
  includeUsageInBackups: false, // 可选；默认排除 usage/
})
```

- 返回冻结的 `PortabilityService`（`contracts/portability-service.ts`）：
  `createBackup` / `inspectBackup` / `restoreBackup` / `exportCourse` / `exportRecords` /
  `deleteRecords` / `resetRecords` / `listArtifacts`。
- Host 接线：`portability.backup`、`portability.export`、`records.export` 用长任务包装（返回 `TaskHandle`）；
  `portability.inspect`、`portability.restore`、`records.delete`、`records.reset` 直接返回 `Result`。
- 默认导出目录 `$DSH_HOME/teaching/exports/<exportId>/`；自定义 `outDir` 必须是绝对路径（否则 `invalid-input`）。
- 每次导出/备份都会在 `exports/`、`backups/` 写 `<id>.manifest.json` 侧车，供 `listArtifacts()` 与 UI 列表读取。
- **恢复前自动备份**：`restoreBackup` 在目标数据目录已有数据时先调用 `createBackup()` 写入 `backups/`；
  返回的 `RestoreReport.warnings` 含该备份绝对路径；失败则中止恢复、原数据不动。
- **恢复后提示**：`RestoreReport.warnings` 固定包含「运行中的 Host 可能需要重启以重新加载缓存」；Host 应原样展示。
- 备份内容：`meta/profile/settings/courses/sessions/activities/learning/environments/runs/sources` 的持久化记录；
  排除 `exports/backups/cache/tasks` 与默认 `usage/`；**不打包原始资料文件**，只记录 `sourcePaths`（含 `exists`）。

## 备份/恢复语义（实测行为）

- `BackupManifest`：`formatVersion=1`、`schemaVersion`（读 `meta.json`）、`entries[{path,bytes,sha256,category}]`、
  `sourcePaths[{sourceId,path,exists}]`、`totalBytes`、`excludesCredentials: true`、插件/应用版本、时间。
- `inspectBackup` 在**不写任何数据**的前提下校验：ZIP 有效性、清单形状、格式版本、schema 兼容、路径安全
  （拒绝 `../`、绝对路径、反斜杠、盘符）、每个条目大小与 sha256、清单外文件。
- `restoreBackup` 顺序：全量校验 → 解包到数据目录旁的临时 staging → JSON 可解析性检查（损坏记录原样恢复并警告）
  → 原资料路径重映射（`remapSources`）与缺失报告 → 存在数据时自动备份 → 逐文件原子写入（`meta.json` 最后）→
  `RestoreReport{restored,skipped,missingSources,needsPathRemap,warnings}`。
  校验失败（篡改/不兼容/路径攻击）时**不写任何文件**，原数据保持可用。
- 引用一致性按 id 关联：课程 `activeRevisionId`、会话 `courseId/courseRevisionId`、活动 `sessionId/courseId`、
  学情 `attempts/mastery/review/notes` 全部来自备份记录，不依赖旧绝对路径；只有 `SourceDocument.originalPath` 会被
  remap 并重新计算 `missing` 标记。

## 记录控制规则（已批准并实测）

| scope | 行为 | 返回计数 |
| --- | --- | --- |
| `session` | 删会话记录 + 消息 JSONL + 本会话活动/活动状态；删本会话产生的尝试与笔记；掌握记录保留历史但移除已删尝试引用 | `sessions/messages/activities/activityStates/attempts/notes/masteryEvidenceRefs` |
| `course` | 删课程 + 全部课程修订 + 会话/消息/活动/活动状态 + 学情；**资料只解除课程关联**（原文件绝不删除）；环境/运行记录作为教学证据保留 | `courses/courseRevisions/sessions/messages/activities/activityStates/attempts/mastery/review/notes/sourcesDetached` |
| `learning` | 只清该课程 attempts/mastery/review/notes；课程与资料保留 | 同上对应键 |
| `notes` | 只清笔记；`id` 给课程 id 时清该课程，否则清全部 | `notes` |
| `all` | 清 `courses/sessions/activities/learning/sources/environments/runs/tasks`；保留 `meta/profile/settings`、导出/备份/usage | 全部分类计数 |

`confirm=true` 为硬性要求：缺失/为 `false` 时返回 `needs-confirmation`；未知 scope 返回 `invalid-input`；不存在对象返回 `not-found`。

## 离线 HTML 导出设计（核心）

- **渲染复用**：导出时用 `src/render` 的 `mountActivity` / `mountDerivation` / `validateActivityPayload` /
  `parseMarkdown+appendMarkdownBlocks` / `katexToHtml`，注入自建最小 `Document` shim（`offline/dom.ts`），
  再把真实渲染出的 DOM 序列化为 HTML。没有改 render，也没有模型 HTML 直出。
- **单文件自包含**：内联 KaTeX 布局 CSS（去掉全部 `@font-face`，公式回退系统字体）、页面 CSS、渲染后的
  Markdown/KaTeX/SVG、quiz 选项、推导步骤壳、代码编辑器、来源 chip；无 `<script src>` / `<link>` / `<img>` /
  `@import` / `url(http…)` / `fetch` / 动态 `import()`。唯一的 `https://` 来自学生消息里的普通 Markdown 链接
  （`<a href>`，用户点击才访问，不是页面资源）。
- **浏览器内交互不依赖宿主**：内联 runtime（约 24.7KB）负责
  graph 参数滑杆实时重算路径 + 动画播放/暂停、derivation 逐步/全部揭示 + 结论、
  quiz 选择/提交反馈/看答案/解析/提示、proof/open 提示/参考答案/rubric 自评勾选、
  来源 chip 展开原文摘录、代码编辑器保留可编辑源码但明确不执行。
  graph 数学（受限表达式求值、断点路径）与 `src/portability/offline/graph-lib.ts` 是**同一份函数源码**：
  测试直接调用 TS 函数，页面通过 `Function.prototype.toString()` 内嵌同一实现，避免两套逻辑漂移。
- **原生实验**：`payload.type === 'code-run'` 的活动源码写入 `native/<activityId>.<ext>`（含 SICP 方言时另写
  `native/sicp-prelude.scm`），并生成 `native/README.md`（语言/会话/源码文件/环境说明/运行方式，含检测到的
  `EnvironmentRecord` 版本与执行方式）；`ExportManifest.nativeSources` 记录语言/路径/运行说明。
- **导出清单**：`ExportManifest{id,formatVersion,createdAt,pluginVersion,courses,files[{path,bytes,sha256}],
  offlineCapable:true,nativeSources,limitations}`；`limitations` 同时包含页面可见的离线说明与本次截断警告，
  明确写入 KaTeX 字体回退、原生实验不执行、答案内嵌、2MB 目标、消息/活动上限等。
- **上限/截断**：每会话最多 300 条消息、200 个活动，最多 100 个会话；单条消息 20,000 字符、代码 100,000 字符
  超限截断并在页面、`warnings`、`limitations` 三处写明；完整源码仍写入 native 文件。
