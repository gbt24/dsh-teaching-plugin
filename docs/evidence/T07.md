## 3. 备份/恢复语义（实测行为）

- `BackupManifest`：`formatVersion=1`、`schemaVersion`（读 `meta.json`）、`entries[{path,bytes,sha256,category}]`、
  `sourcePaths[{sourceId,path,exists}]`、`totalBytes`、`excludesCredentials:true`、插件/应用版本、时间。
- 备份内容：`meta/profile/settings/courses/sessions/activities/learning/environments/runs/sources` 的持久化记录
  （含 `sources/<id>/revisions`、`search` 等派生数据）；排除 `exports/backups/cache/tasks` 与默认 `usage/`；
  **不打包原始资料文件**，只记录路径与 exists。
- `inspectBackup` 在不写数据的前提下校验：ZIP 完整性、清单形状、格式版本、schema 兼容、路径安全
  （拒绝 `../`、绝对路径、反斜杠、盘符）、每条目大小与 sha256、清单外文件。
- `restoreBackup` 顺序：全量校验 → staging 解包旁目录 → JSON 可解析性检查（损坏记录原样恢复并警告）→
  `remapSources` 重映射原资料路径并统计缺失 → 目标已有数据时自动备份 → 逐文件原子写入（`meta.json` 最后）→
  `RestoreReport{restored,skipped,missingSources,needsPathRemap,schemaMigratedFrom?,warnings}`。
  校验失败（篡改/不兼容/路径攻击）时**不写任何文件**，原数据保持可用。
- 引用一致性按 id：课程 `activeRevisionId`、会话 `courseId/courseRevisionId`、活动 `sessionId/courseId`、
  学情 attempts/mastery/review/notes 均来自备份记录；只有 `SourceDocument.originalPath` 会被 remap 并重算 `missing`。

## 4. 记录控制规则（已批准并实测）

| scope | 行为 | 返回计数键 |
| --- | --- | --- |
| `session` | 删会话记录 + 消息 JSONL + 本会话活动/活动状态；删本会话产生的尝试与笔记；掌握记录保留历史但移除已删尝试引用 | `sessions/messages/activities/activityStates/attempts/notes/masteryEvidenceRefs` |
| `course` | 删课程 + 全部课程修订 + 会话/消息/活动/活动状态 + 学情；**资料只解除课程关联**（原文件绝不删除）；环境/运行记录作为教学证据保留 | `courses/courseRevisions/sessions/messages/activities/activityStates/attempts/mastery/review/notes/sourcesDetached` |
| `learning` | 只清该课程 attempts/mastery/review/notes；课程与资料保留 | 对应键 |
| `notes` | 只清笔记；`id` 给课程 id 时清该课程，否则清全部 | `notes` |
| `all` | 清 `courses/sessions/activities/learning/sources/environments/runs/tasks`；保留 `meta/profile/settings`、导出/备份/usage | 全部分类计数 |

`confirm=true` 为硬性要求：缺失/为 `false` 返回 `needs-confirmation`；未知 scope 返回 `invalid-input`；不存在对象返回 `not-found`。

## 5. 离线 HTML 导出设计

- **渲染复用**：导出时用 `src/render` 的 `mountActivity` / `mountDerivation` / `validateActivityPayload` /
  `parseMarkdown+appendMarkdownBlocks` / `katexToHtml`，注入自建最小 `Document` shim（`offline/dom.ts`），
  再把真实渲染出的 DOM 序列化为 HTML。没有改 render，也没有模型 HTML 直出。
- **单文件自包含**：内联 KaTeX 布局 CSS（去掉全部 `@font-face`，公式回退系统字体）、页面 CSS、渲染后的
  Markdown/KaTeX/SVG、quiz 选项、推导步骤壳、代码编辑器、来源 chip；无 `<script src>` / `<link>` / `<img>` /
  `@import` / `url(http…)` / `fetch` / 动态 `import()`。唯一 `https://` 来自学生消息里的普通 Markdown 链接
  （`<a href>`，用户点击才访问，不是页面资源）。
- **浏览器内交互不依赖宿主**：内联 runtime（24,732 B）负责
  graph 参数滑杆实时重算路径 + 动画播放/暂停、derivation 逐步/全部揭示 + 结论、
  quiz 选择/提交反馈/看答案/解析/提示、proof/open 提示/参考答案/rubric 自评勾选、
  来源 chip 展开原文摘录、代码编辑器保留可编辑源码但明确不执行。
  graph 数学（受限表达式求值、断点路径）与 `offline/graph-lib.ts` 是**同一份函数源码**：
  测试直接调用 TS 函数，页面通过 `Function.prototype.toString()` 内嵌同一实现，避免两套逻辑漂移。
- **原生实验**：`code-run` 活动源码写入 `native/<activityId>.<ext>`（SICP 方言另写
  `native/sicp-prelude.scm`），并生成 `native/README.md`（语言/会话/源码文件/环境说明/运行方式，含检测到的
  `EnvironmentRecord` 版本与执行方式）；`ExportManifest.nativeSources` 记录语言/路径/运行说明。
- **导出清单**：`ExportManifest{id,formatVersion,createdAt,pluginVersion,courses,files[{path,bytes,sha256}],
  offlineCapable:true,nativeSources,limitations}`；`limitations` 同时包含页面可见离线说明与本次截断警告。
- **上限/截断**：每会话最多 300 条消息、200 个活动、100 个会话；单条消息 20,000 字符、代码 100,000 字符
  超限截断并在页面、`warnings`、`limitations` 三处写明；完整源码仍写入 native 文件。

## 8. 局限、风险与 Host 侧建议

1. **真实浏览器断网/桌面 UI 未验证**（见 §6.5）；这是 AC14 剩余的人工验收项。
2. **`portability.restore` 在 Host 路由是同步直接返回**：恢复包含「校验整个归档 + 自动备份当前数据 + staging +
   逐文件写入」，大规模数据下可能耗时较长，且当前未传 abort signal、无任务进度/取消。
   **建议 Host**：像 backup/export 一样用 `services.tasks.start` 包装并传 `context.signal`；至少 UI 显示
   “恢复中，请勿关闭”；完成后必须展示 `RestoreReport.warnings`（尤其“已自动备份到 …”和“可能需要重启”）。
3. **`portability.export` 的 API body 没有 `includeNotes`**：`ExportRequest.includeNotes` 目前只能由服务层传，
   UI 无法请求导出笔记（Host 路由也未透传）。**建议 Lead 扩展 `contracts/api.ts` 的请求 body**（加
   `includeNotes?: boolean`）并在路由透传；否则页面默认不含笔记（页面会显示“有 N 条笔记未包含”）。
4. **恢复不是整目录事务**：校验/staging 在写入前完成，单文件 tmp+rename；若磁盘在写入中途失败，
   已写入的备份文件仍有效、未写入记录保持原样，返回 `storage` 错误与已写入数量。已验证失败路径不损坏现有记录。
5. **恢复后 Host 内存缓存**：service 不重启 Host；`RestoreReport.warnings` 已明确提示重启以重新加载缓存，
   需要 UI/Lead 负责展示。
6. **渲染器结构依赖**：`graphLayoutOf` 依赖 graph 渲染帧前 10 条 `<line>`（5 竖 5 横），derivation/quiz 注入
   依赖 renderer 类名与按钮文案；render 若改 DOM 结构需同步更新 `offline/**`，现有测试会失败提示（未改 render）。
7. **KaTeX 专用字体未内嵌**（去 `@font-face`）：公式用系统字体回退，已写入 `ExportManifest.limitations` 与页面可见说明。
8. **quiz 答案内嵌**：页面脚本数据包含 `correctOptionIds`/解析（离线判分需要），已在页面说明；不是防作弊产品。
9. **离线交互不持久化**：滑杆/动画/quiz/自评只在页面内生效，不写回学习记录（页面已说明）。
10. **备份/导出一次性读入内存**：fflate `zipSync` 与文件读取都在内存完成（备份逐项计算 sha256）；个人规模按 R35
    可接受，但超大库的内存/耗时未做流式优化，未测超大规模真实库。
11. **schema 迁移**：当前 `SCHEMA_VERSION=1`，只接受同版本恢复；更旧 schema 明确报「需要迁移」而不是静默转换。
12. **删除规则的产品含义**：删课程保留环境/运行记录与 source 派生数据（资料仅解除关联）；`all` 不清理
    `exports/backups/usage`。如产品要更彻底清理由 Lead 确认后调整。
13. **dev 数据是活跃测试数据**：§6.3/§6.4 的 numbers 是 2026-11-04 20:03 +08 的运行时刻快照；之后 Lead 的
    测试可能继续改变 dev 目录内容，重跑命令即可重新生成快照，不影响结论。
