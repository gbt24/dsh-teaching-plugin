## 改动与接口（T01 冻结）

- **包布局**：`packages/teaching-core`（纯 Node/TS 域逻辑，不 import Harness）、`packages/dsh-plugin`（可安装 bundle：Host + Client + patch）。
- **公共契约**（`packages/teaching-core/src/contracts/`，冻结）：ids/result/task/source/course/session/activity/learning/experiment/portability/corpus/teaching/learning-service/api。客户端↔Host 全部操作在 `api.ts` 定义为 `/api/teaching/<op>` exact Fetch 路由 + `Result` JSON 封套 + chat SSE。
- **本地存储**（`storage/`）：`LocalState`（原子写、同文件串行、路径越界拒绝、schema 版本检查、损坏记录显式报错、JSONL 尾行容错）+ 四个仓库（Profile/Course/Session/Learning）。目录布局见 `storage/layout.ts`；原资料只读，衍生数据全部在数据目录。
- **模型 seam**（`model/`）：`ModelClient`（info/stream/complete）+ `HarnessModelAdapter`（Host 侧用 `ctx.llm.stream`，带超时、最多一次重试、usage 记录、`sessionId` 路由元数据）；`ScriptedModelClient` 供确定性测试。
- **Host 桥接**（`packages/dsh-plugin/src/host/`）：插件入口 `apply()`、`/api/teaching/*` 全路由、长任务注册表（进度/取消/重启中断标记）、T01 最小纵向切片（文本类导入、headings→课程草案、有来源讲解 + 活动提案、尝试与最小掌握规则、代码运行）。
- **客户端**（`src/client/`）：**当前为占位入口**（侧栏图标 + 面板标题），完整工作区由 T05 交付；构建入口/包格式已冻结（`window.__ModuleLoader__.load` 包装，external react）。
- **构建**：`scripts/build-plugin.mjs` 产出 `packages/dsh-plugin/lib/index.js`（Host ESM，core 内联）与 `lib/client.js`（浏览器 half）。
- **安装**：bundled CLI `dsh plugin --profile teaching-dev add packages/dsh-plugin`（T00 已证同路径）；desktop profile 安装仍待应用内 plugin_manager/用户批准。
