# 协作契约草案 v0

用途：让实现任务在公共语义一致后可并行。以下是自有 module 的 interface 设计，**不是 Harness SDK 声明**。T00 核实宿主接口，T01 将语义冻结为实现所用的 schema/type。修改公开语义由整合负责人统一提交。

## 共享规则

- ID 在本地项目内稳定；所有内容/活动/课程修订携带版本。时间使用明确时区或 UTC，展示遵循学生设置。
- 命令携带操作 ID、学习上下文、必要的预期修订；重试不能重复创建导入、尝试或实验结果。
- 长操作返回任务身份、阶段、进展与可取消信息；部分完成和不确定性是结果，不只是一条异常。
- 失败结果区分不可用、待确认、取消、冲突、失败、未验证。成功执行不自动等于知识正确或学生掌握。
- Client 输入由 Host 验证；Host 提交后的状态是权威，重连能重新读取。用户删除是显式数据操作，不能被“历史只追加”规则阻止。

## 领域对象

| 对象 | 必要语义 |
| --- | --- |
| SourceDocument / SourceRevision | 同一资料身份与某次内容快照分开；记录格式、指纹、状态、可定位内容及不确定性。 |
| SourceAnchor | 指向特定修订的原始位置；可解析到文件/页区域/段落/幻灯片/代码行/Notebook 单元，并报告缺失或版本差异。 |
| EvidenceReference | 标明课程原资料、其他课程、外部网页或模型补充；推导引用其前提，不伪造原文出处。 |
| CourseRevision | 课程目标、资料角色、概念/先修关系与学习顺序；草案和学生确认的生效版本分别保存。 |
| LearningContext | 学生本地身份、当前课程修订、目标、基础、语言偏好、当前学习位置。 |
| LessonActivity / ActivityRevision | 类型、学习目标、输入、参数/代码、呈现描述、当前状态、来源、验证状态；不依赖某次聊天 DOM。 |
| LearningAttempt | 原回答、题目/活动版本、提示层级、答案是否已展示、是否独立、客观验证及 rubric 评价。 |
| MasteryAssessment | 评价结论、支持证据、未覆盖维度、争议、自述与需要复核的原因；不覆盖原始尝试。 |
| EnvironmentPlan / EnvironmentRecord | 需求、已有能力、独立配置位置、所需改动、资源/兼容限制、版本、实际验证结果和清理信息。 |
| ExperimentRun | 代码与环境修订、输入/参数、执行状态、输出/错误、验证结果、资源与取消情况。 |
| ExportManifest / BackupManifest | 格式版本、资源清单、校验、原路径引用、可独立运行部分、外部环境要求、恢复缺失项。 |

## Module interfaces

| Module | 调用方需要的操作 | 不变量与错误 |
| --- | --- | --- |
| Corpus | 提交导入/刷新；查询证据；解析来源；提出/确认课程修订 | 按课程与修订查询；更新不偷换历史出处；识别不确定内容回传；失效来源不假装可跳转。 |
| Teaching | 开始/继续；处理插入问题；选择/切换活动；请求提示/解答；接收尝试结果 | 保留目标与恢复位置；讲解/补充可追溯；未验证结果可见；跳过不创建掌握证据。 |
| Activities | 创建/读取/修改活动；恢复视图；输出可导出的描述 | 修改带预期修订，冲突可处理；参数/代码改变使旧运行结果对应旧修订。 |
| Experiments | 检查/准备环境；提交/取消运行；读取执行证据 | 记录真实运行器与版本；依赖隔离和执行限制分别验证；超限/缺依赖/不兼容可区分。 |
| Learning | 保存尝试与评价；读取学习档案；记录异议/重检；提供复习候选 | 辅助/独立完成分开；证据可查；学生自述与已检验状态分开；旧资料变化标记复核。 |
| LocalState | 本地原子提交；读取修订；迁移；导出；删除/重置 | 并发提交不覆盖较新版本；删除同步处理索引和派生状态；恢复失败保持原数据可用。 |
| Portability | 导出活动/笔记/代码；备份；检查/恢复备份 | 列明脱离宿主可运行范围；校验失败/路径缺失显式报告；不把宿主凭据打包。 |
| HarnessBridge | 激活/卸载；收发命令与状态；调用当前模型与可用宿主能力 | 版本和能力显式检查；Client 不持有 Host 私有执行权限；重复加载不重复注册。 |

## 任务状态与学习状态分离

长任务：queued → running → completed / partial / failed / cancelled。completed 只说明该任务完成；内容验证、课程确认、掌握评价是独立字段。

资料：发现 → 处理 → 可用 / 部分可用 / 待核对 / 失败。一个资料问题不锁住所有已可用课程。

学习：讲解进度、练习进度、掌握评价分别维护。评价必须能回答“依据哪些尝试、展示过哪些帮助、哪些条件尚未覆盖”。展示完整答案后的同题复答不能伪装成此前的独立迁移证据。

## 版本与演进

T01 记录首个本地数据 schema 与活动 schema 版本。之后的任务提供升级测试与历史数据样例。恢复旧数据、源资料变化、重新评价和用户清除都通过同一 interface 处理，避免各 UI 私自改写存储。
