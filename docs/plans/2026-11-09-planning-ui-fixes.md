# 已完成：规划/资料 UI 修复（2026-11-09）

用户已确认此计划；DSH 0.2.2 兼容性修复后已实施。

1. 左侧“资料”区 UI
- `MaterialsPanel` 的 `.ai-material-row/.ai-materials-panel/.ai-material-origin` 在 `styles.ts` 中缺少样式，默认 button 被撑成巨大胶囊。
- 修复：紧凑行、单行省略、列表 max-height + scroll、标题行对齐、本地/网页徽标固定宽度、缺失提示；增加“查看全部资料”切换右侧来源标签。

2. 访谈选项改为真正选择
- 当前点击选项只把文本写入 textarea，选中态不明确、容易误判。
- 修复：选项用 radio/card 选择，选中态独立于输入框；“自定义回答”才显示 textarea；答案状态分离；未答提示；“全部按推荐”正确选中；键盘/aria 支持。

3. 简化计划确认页
- 当前 PlanBrief 全字段表单过多且大量空字段，用户不知道填什么。
- 修复：默认显示 AI 生成的计划摘要（标题/目标/章节主题/检索主题）；只保留标题、目标、每周投入/周期 3 个轻量调整项；完整字段放进“高级编辑”折叠；主按钮“确认计划并搜索资料”，次按钮“仅保存/按计划直接建课/取消”；缺失字段用默认值或重新生成，不显示空白巨大表单。

实现时先 1→2→3；验收：资料区不撑爆、选项选中态明确、首屏不再是大表单；tsc/client/全量测试/构建通过。
