# 三角恒等式速查（跨章工具）

本页是跨章推导工具：只需熟记两角和差公式，其余公式可现场推导。

## 和差化积

$$\sin A + \sin B = 2 \sin\frac{A+B}{2}\cos\frac{A-B}{2}$$

## 倍角与降幂

$$\cos 2A = 1 - 2\sin^2 A = 2\cos^2 A - 1$$
