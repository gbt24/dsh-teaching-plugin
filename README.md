# AI 知识库教学插件

面向 DeepSeek Harness 桌面应用的个人学习插件。学生以本地资料建立课程，在对话与持续教学区域中学习、实验、练习，并依据实际作答记录理解与迁移能力。

## 当前状态

- 需求基线 v1.0 已于 2026-11-04 经用户确认，覆盖 40 项访谈决策。
- 本目录是独立项目入口；当前交付为需求、设计提案、验收与实现任务包。
- 本聊天负责需求与计划；由用户自行指定和派发实现 agent。产品功能是否完成，以任务证据和桌面实际验收为准。
- 分阶段实施用于组织交付，最终 v1 范围保持全部已确认需求。
- 此前派发的 agent 已停止。仅保留只读 preflight 资料：本机 Desktop 为 `0.2.1-rc.5`；未创建产品代码、安装插件或修改 desktop profile。后续由用户自行派发任务。

## 第一个任务

用户可以将 **T00：桌面兼容性与最小真实集成验证** 交给自己的实现 agent。先核对目标桌面版本和官方接口证据，再验证插件加载、模型调用、Host/Client 通信、教学区域与持久化能力。接口不确定时做可运行验证，不猜测 SDK。

当前没有承诺具体工期、模型费用上限或响应时间 SLA。实现过程中测量并报告这些指标，不能将“质量优先”解释为无限预算。
