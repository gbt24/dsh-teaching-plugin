# 实现任务卡

每次只领取用户分配的任务；前置、完成和验证标准以本卡与 [计划](../docs/plan.md) 为准。全部任务服务于最终 v1，不代表已实现；任务卡供用户自行转交，不触发自动执行。

## T00 — 真实桌面技术基线与最小集成

- **角色**：实现负责人；前置：已确认需求。
- **读取**：START-HERE、requirements、research/harness-desktop-integration、technical-decisions。
- **写入范围**：`spikes/desktop/`、`docs/evidence/T00*.md`；必要的技术事实可更新 technical-decisions，公共产品需求保持稳定。
- **步骤**：先只读查找 Desktop 与版本/架构/bundled CLI，回报 preflight；锁定对应官方声明与依赖；创建最小 bundle，验证 Host/Client/Slot、业务通信、当前模型、取消、数据重启恢复；验证最小文件/子进程路径和独立 HTML 导出路线。
- **产物**：可复查 spike、版本证据、安装/卸载方法、能力 gap 与冻结建议；证据文件中记录实际改动的 desktop profile 内容，确保测试贡献可移除。
- **完成**：研究报告 V1–V8 的结论均有实测或明确缺条件；实际桌面关键通路通过才能标 P0 验证通过。Desktop 不存在时完成 preflight 子任务并记录阻断，不能写成完整 T00 完成。
- **覆盖**：R11/R33/R39，AC01 及 AC06/AC14 的可行性。

## T01 — 项目基座与最小真实学习流程

- **角色**：实现负责人；前置：T00 关键桌面通路通过。
- **写入范围**：root 构建与依赖、Host bridge、LocalState、共享 contracts、最小纵向流程；实际源码布局在此冻结。
- **步骤**：确定发布布局/锁文件/开发入口；把 contracts 草案落为公开 schema/type；连接本地存储、一个文本来源、一项活动与一次学生尝试；支持重启恢复。
- **产物**：能够在 Desktop 实操的一条小流程、schema 版本、可分配目录与后续任务调用示例。
- **完成**：选课→有来源讲解→持续活动→保存学生尝试→重启续学通过；修订、来源、辅助/独立状态的关键 integration tests 通过。构建入口使用实际环境生成，不照抄未核验命令。
- **覆盖**：R01/R05/R06/R14/R15/R29 基座，AC05/AC06/AC09 最小路径。

## T02 — 知识库、课程和来源修订

- **角色**：知识库实现 agent；前置：T01。
- **所有权**：Corpus、格式/检索 adapters、资料 fixtures。共享存储与 schema 变更由负责人整合。
- **步骤**：实现 A–E 导入和问题清单；原文位置与不确定性；中英/跨课程检索；课程草案确认；增量变化及受影响引用；进度/取消和已就绪课程可用。
- **产物**：真实多格式 corpus、检索/定位基准、变更与异常报告。
- **完成**：AC02/03/04/10 的知识部分通过；公式/图表关键不确定性可传给 Teaching；源文件不被改写；规模导入与可恢复进展有样例。
- **覆盖**：R02/R04/R10/R12/R13/R19/R21/R23/R24/R35/R38。

## T03 — 目标驱动的自适应教学

- **角色**：教学实现 agent；前置：T01/T02；消费 Activities 契约，不抢占 T05 实现。
- **所有权**：Teaching、模型/联网使用策略、教学样例；Host 模型调用依赖通过 bridge。
- **步骤**：目标与基础输入、按需诊断、教学形式选择、追问与回到课程；直觉/准确表述/条件/类比边界；本地与跨课/外部来源区分；冲突与资料不足；中文/英文/双语及分步反馈。
- **产物**：不同学科的教学结果、学习流程与可校验活动调用。
- **完成**：AC04/05/16/18 通过；当前模型复用与缺能力分支明确；学生切换形式后保留目标，引用有真实依据，联网失败不造来源。
- **覆盖**：R01/R02/R04/R06/R07/R08/R09/R10/R16/R19/R20/R21/R22/R34/R38/R39。

## T04 — 练习、掌握证据与复习

- **角色**：学情实现 agent；前置：T01/T03。
- **所有权**：Learning、rubrics、练习与学情 fixtures。
- **步骤**：可跳过学习循环、提示层级、完整答案、尝试独立性；解释/反例/变式/迁移评价；主客观验证证据；错题、争议与重检；跨次档案和使用中复习。
- **产物**：四类课程适用的评价细则与 evidence 数据流，学生可解释的掌握记录。
- **完成**：AC07/08/09 通过；跳过、看答案、模型代答不产生虚假独立掌握；开放题保留判断依据和局限；学生纠正有记录。
- **覆盖**：R03/R07/R09/R15/R17/R18/R25/R28/R29。

## T05 — 持续教学区域、交互活动与初始运行器

- **角色**：交互与实验实现 agent；前置：T01；可与 T02 并行。
- **所有权**：Activities、Client 学习工作区、Experiments 初始 adapters。契约修改通过负责人整合。
- **步骤**：图形/动画/公式推导与代码活动；直接编辑和对话修改；Python/JS/Scheme 实际执行；活动修订与实际输出；取消、错误、刷新/重连/重启恢复。
- **产物**：可恢复活动模型、宿主内 renderer、三语言证据；为 T07 独立 renderer 提供稳定描述。
- **完成**：AC06 与 AC11 初始三语言通过；Scheme 与资料方言相符；运行结果对应具体代码/参数版本；教学页面与 Host 执行权限分离。
- **覆盖**：R08/R14/R26/R28/R36。

## T06 — 自动环境扩展、核验与资源替代

- **角色**：交互与实验实现 agent；前置：T05，消费 T03 教学输入。
- **所有权**：Experiments 环境发现/准备/核验 adapters，与独立环境元数据。
- **步骤**：从课程需求识别缺失环境，独立配置并冒烟；失败清理/取消与系统改动选择；验证执行和数值结果；重型实验降规模并解释差别。
- **产物**：至少一种初始三语言之外的轻量环境扩展实证，通用流程与资源替代样例。
- **完成**：AC11/12/13 实验部分通过；虚拟环境与执行约束分别验证；配置失败不破坏已可用课程和环境；不把任意安装成功率作无依据保证。
- **覆盖**：R26/R28/R31/R32/R34。

## T07 — 成果、记录控制与备份迁移

- **角色**：成果与数据实现 agent；前置：T02/T04/T06，renderer 可在活动契约稳定后提前开发。
- **所有权**：Portability、独立 renderer、记录管理界面；存储/迁移通过 LocalState interface。
- **步骤**：导出笔记/代码/离线交互；明确原生执行依赖；记录纠正/导出/删除/重置；备份清单、校验、格式迁移和资料路径重映射。
- **产物**：可独立使用导出包、可恢复备份、数据控制与异常恢复演示。
- **完成**：AC09/10 的历史与 AC14/15/18 通过；关闭 Desktop 及断网检验 HTML；换路径恢复后引用和证据一致，缺资料显式报告。
- **覆盖**：R15/R19/R23/R27/R29/R30/R37/R38。

## T08 — 桌面分发、规模与教学验收

- **角色**：实现负责人组织整合与人工评审；前置：T02–T07 全部必需结果。
- **所有权**：打包/发布配置、安装文档、整合修复、验收证据；跨 module 修复通知各 owner。
- **步骤**：检查归档产物/兼容范围；真实 Desktop 安装升级卸载；个人多课程规模、取消/断网/失败/恢复；四类真实资料与学习者教学评审；逐项 R/AC 追踪。
- **产物**：可分发包、兼容平台与版本表、真实安装说明、测量报告、完整验收报告。
- **完成**：AC01–AC22 均有证据或明确未通过原因；所有 R 均覆盖；阻挡需求的未通过项解决后才能称 v1 完成。仅演示、mock、模型自测不能替代人工教学评审。
- **覆盖**：全部 R，重点 R11/R33/R34/R35/R40。
